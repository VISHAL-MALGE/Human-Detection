Developed a real-time human detection system using YOLO (You Only Look Once) object detection model and OpenCV. The system captures video from a webcam, detects humans in the video stream, and plays a beep sound when a human is detected.

Overview
Human-Detection is a robust developer tool that utilizes YOLOv8 and OpenCV to perform real-time
human detection within video streams. It captures webcam footage, processes frames instantly, and
provides immediate auditory alerts upon detecting people, making it ideal for surveillance and monitoring
applications.
Why Human-Detection?
This project aims to deliver fast, accurate human presence identification. 

The core features include:

Object Detection: Uses YOLOv8 for high-precision, real-time human detection.

Instant Alerts: Provides immediate auditory feedback when a person is detected.

& Webcam Integration: Seamlessly captures live video streams for continuous monitoring.

Data Annotation: Supports precise labeling for training and evaluating detection models.

Responsive Performance: Designed for quick, reliable detection to meet real-time application
needs.
